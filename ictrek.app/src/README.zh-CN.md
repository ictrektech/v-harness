# v-harness

多用户 agent 工作台。每位用户拥有独立的会话、工作区和产物，互相不可见。

## 使用

1. 在 VOS 中打开 v-harness，**无需注册或登录**：平台身份自动接入。
2. 在左侧会话栏新建对话，直接描述你要完成的事。
3. agent 会在你的工作区里读写文件、执行命令，产物出现在「日常」目录或你指定的项目目录。

## 目录

- `workspace/日常/`：没有指定项目时的默认落点，闲聊与临时任务都在这里。
- `workspace/<项目>/`：自建项目目录。

## 注意

- 每位用户独立进程与独立账号，任何用户都读不到其他人的会话、文件或凭据。
- 文件管理只展示你自己的 `workspace/`，隐藏文件不可下载。
- 请在 V-Scheduler 中添加模型，再到设置 → 模型刷新列表并选择默认模型。当前 VOS 账号可见的聊天、Responses、Messages 和文本补全模型均可在对话中下拉选择，无需另行登录 DeepSeek 或填写 API Key。纯文本补全模型不支持工具调用。
