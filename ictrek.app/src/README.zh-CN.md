# v-harness

多用户 agent 工作台。每位用户拥有独立的会话、工作区和产物，互相不可见。

VOS 版本以前缀跟随官方 DSH 版本，后缀 `.vos.xx` 记录本项目的发布次数，例如 `0.2.2-rc.1.vos.01`。同一官方版本下递增，切换官方版本后从 `.vos.01` 重新计数。

## 使用

1. 在 VOS 中打开 v-harness，**无需注册或登录**：平台身份自动接入。
2. 在左侧会话栏新建对话，直接描述你要完成的事。
3. agent 会在你的工作区里读写文件、执行命令，产物出现在「日常」目录或你指定的项目目录。

## 目录

- `workspace/日常/`：没有指定项目时的默认落点，闲聊与临时任务都在这里。
- `workspace/<项目>/`：自建项目目录。

## 注意

- 每位用户独立进程与独立账号，任何用户都读不到其他人的会话、文件或凭据。
- 文件管理只展示你自己的 `workspace/`，隐藏文件不可下载。
- 请在 V-Scheduler 中添加模型，再到设置 → 模型刷新列表并选择默认模型。当前 VOS 账号可见的聊天、Responses、Messages 和文本补全模型均可在对话中下拉选择，无需另行登录 DeepSeek 或填写 API Key。纯文本补全模型不支持工具调用。

## 内置插件

首次打开默认使用经典 Agent 界面。DS Bot 已预装，需使用时在「插件」中启用。启用状态按用户保存。

- **自媒体工作台**。登录 VOS 并打开 v-harness，从侧栏进入「自媒体工作台」。如果当前是 DS Bot 界面，先从账户菜单打开「设置」，在「模式」切换到「经典 Agent 模式」。先在「灵感」记一条素材，再点开卡片生成脚本、标题、封面、配图和分镜。可在「排期」安排发布，并在「复盘」手动录入或导入数据。写稿沿用 v-harness 的默认模型，也可在工作台中另选模型。需要生成图片时，在工作台设置中配置图片服务或选择已接入的订阅生图工具，并先试画一张。首次打开时可使用示例数据，也可点「示例数据 · 清空」后开始记录。[上游使用说明](https://github.com/woniuniuniu/dsh-media-desk)
- **IM 机器人**。进入「设置 → IM机器人」，选择渠道，按页面提示扫码或填写机器人凭据，再绑定工作区、选择模型并设置允许访问的会话。确认连接后，从相应聊天应用给机器人发一条测试消息。连接失败时检查平台权限、凭据和网络。各渠道接入方式见[上游使用说明](https://github.com/xmanrui/dsh-im)。
- 两个入口均使用当前 VOS 用户的隔离环境。自媒体工作台的 `/media-desk/*` 是该插件网页使用的会话接口，随插件版本发布。IM 平台接入由各渠道适配器管理。
- **插件下载**。插件市场默认使用「全球」下载区域，标准 npm 安装使用官方源。可在插件市场设置中手动调整下载区域。

在「设置 → API 文档」查看 VOS OAuth2 鉴权、创建会话、提交任务、读取结果及错误处理。

## VOS 运维

打开「账号菜单 → 设置 → VOS 运维」，由当前 VOS 系统管理员点击「授权诊断」。每次授权持续 15 分钟，退出诊断可提前结束。其他角色会收到权限提示。

- 启动失败时先查看应用的状态、最近错误和 VOS 工作流，再打开相应主栈容器最近 150 行日志。日志上限 512 KiB，日志驱动不可读或响应超过上限时会报错。
- 输入宿主机端口，查找 Docker 发布端口对应的容器和协议。宿主机进程、host 网络监听和未发布的端口不在此列表内。
- 容器清单标明对应的应用版本。只有可识别、属于仍在本机安装的应用、版本与当前安装不同且已退出的主栈容器可清理。删除容器会移除其可写层，保留卷。带标签但没有容器引用的镜像仅供排查，只有无标签、无摘要且没有任何容器引用的镜像可清理。
- 重启应用或清理对象时，核对预览中的应用 ID、容器 ID 或镜像 ID，点击「确认执行」或「跳过」。预览 60 秒内单次有效，目标发生变化时必须重新预览。重启由 VOS 执行，受理后会显示任务 ID。

VOS 系统管理员在会话里选择「完全访问（VOS 运维）」即可直接诊断。Agent 提出停止容器、重启应用或清理时，会话里会显示具体目标并请管理员确认。会话继续使用工作区沙箱。支持的操作见「设置 → API 文档」。

在 DS Bot 中打开「设置 → 模型」。「V-Scheduler」区可从现有目录选择默认模型，也可刷新列表。「自定义模型供应商」仅统计在 DS Bot 中添加的供应商，仍可点击「添加供应商」配置，也可进入「高级设置」。Agent API 的模型接口保持原有契约。

如果旧版 VOS 容器占用端口或持有 runner 文件锁，在会话中选择「完全访问（VOS 运维）」并让 Agent 检查应用。核对「停止旧版容器」提议，点击「确认执行」或「跳过」。刷新清单后，可再请求重启当前应用或单独清理已退出的容器。停止操作保留容器及数据。`stoppable` 表示容器可识别、处于运行或重启中，所属应用已安装或停止，容器版本与当前安装版本不同，且所属应用不是 v-harness。停止前会重新校验当前安装版本和安装 ID。目标变化或不符合条件时返回 409 `target-changed`。

查应用状态或请求重启时，请使用清单中的应用 ID。修复提议等待用户确认，返回 `executed: false`。已有提议时，HTTP 409 `confirmation-pending` 返回该提议的 `action`、`id` 和剩余秒数 `expiresIn`。请在会话里确认或取消。过期或已使用的确认返回 409 `confirmation-unavailable`。应用状态收到 Docker ID 时返回 400 `app-id-required`，请在清单里看容器状态或用日志查询读取输出。

### 宿主机管理

VOS 系统管理员打开会话，点击「宿主机管理」，再点击「开启宿主机管理」。Agent 可列出宿主机 Docker 容器、查看近期日志，并按完整容器 ID 提议启动、停止、重启或删除。执行前请在会话里核对目标并确认。删除要求容器已停止，数据卷保留。点击「关闭宿主机管理」可提前结束。授权在 30 分钟后过期，每次调用都会核验管理员角色和 VOS 登录会话。接口见「设置 → API 文档」。

### 批量清理

让 Agent 把要删除的对象放进同一条清理提议。确认窗口随 VOS 界面语言切换，列出整批对象。点击一次「确认执行」或「跳过」。执行后会显示每个对象的删除结果。VOS 运维支持识别到的旧版 `created` 和 `exited` 容器。批量上限和错误处理见 API 文档。
